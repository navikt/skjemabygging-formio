# Test case 08

Hovedfokus er å teste at brukeropplysninger blir riktig satt i forespørselen til førstesiden.

- `tc08a` dekker person med fødselsnummer som bruker
- `tc08b` dekker organisasjon som bruker
- `tc08c` verifies the ETTERSENDELSE cover page body for a static PDF form.
- `tc08d` dekker person uten fødselsnummer som ukjent bruker med navn og adresse
- `tc08e` verifies Sendinn's cover-page-only request with Nav-unit routing. The selected attachment is printed in English and archived in Bokmål. Filtered-out attachments are absent.
- `tc08f` verifies that a paper other-document description is used verbatim in both document lists. An available but unselected attachment is absent. Both Sendinn variants return the existing PDF fixture only after the actual backend request matches.
- `tc08g` verifies an identified Sendinn user with English printed labels and Bokmål archived labels. Documents retain authored order even when selected in reverse order. A 50-character other-document description retains its repeated internal whitespace in both lists. The existing digital title control's boundary-whitespace formatting is unchanged.
- `tc08h` verifies an unidentified Sendinn user's name, postal address and Nav-contact routing, without an identified user. The browser then switches to multiple people and reuses `tc08e` to prove that inactive person and contact answers no longer reach the generator.
- `tc08i` verifies a form published in Nynorsk, with a Nynorsk printed attachment label, Bokmål archived label and no collected user. Its form and static translations are local fixtures, not proof that production translations have been published.

The six Sendinn collection-settings combinations reuse `tc08f` for hidden collection and `tc08e` for visible Nav-unit collection. All Sendinn verification variants return the existing PDF fixture only after comparing the complete real backend request, without ignored fields.
