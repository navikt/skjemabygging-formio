# Test case 08

Hovedfokus er å teste at brukeropplysninger blir riktig satt i forespørselen til førstesiden.

- `tc08a` dekker person med fødselsnummer som bruker
- `tc08b` dekker organisasjon som bruker
- `tc08c` verifies the ETTERSENDELSE cover page body for a static PDF form.
- `tc08d` dekker person uten fødselsnummer som ukjent bruker med navn og adresse
- `tc08e` verifies Sendinn's cover-page-only request with Nav-unit routing. The selected attachment is printed in English and archived in Bokmål. Filtered-out attachments are absent.
- `tc08f` verifies that a paper other-document description is used verbatim in both document lists. An available but unselected attachment is absent. Both Sendinn variants return the existing PDF fixture only after the actual backend request matches.
