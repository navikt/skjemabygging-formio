# Test case 22

Verifies that deleting a repeated attachment before uploading a file, or while its upload is pending, removes it from the final no-login submission. A successful response arriving after cancellation must trigger deletion of that file without restoring the removed row.

The final submission contains exactly four attachments: personal ID (`K2`), followed by the authored attachment order (`r7`, `V3`, `N6`). The first repeated attachment remains; the deleted second attachment is absent. All stable request fields are compared with `tc22-innsending-nologin-soknad-body.json`; generated application/file IDs and document contents are excluded by the existing mock route variant.
